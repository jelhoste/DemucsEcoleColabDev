Comparer les détecteurs de mélodie

Ce fichier contient plusieurs mélodies détectées sur la même voix. Le découpage en notes est identique pour tous : seule la détection de hauteur diffère. Choisissez celle qui s'affiche (piano roll, bande, liste) ; c'est celle qui sera exportée.
Une ligne par détecteur, même échelle de hauteur. Clic = aller là.

Exporter la partition (MusicXML / ABC)

La mélodie affichée (version choisie ci-dessus) est calée sur la grille des temps détectés, quantisée, puis écrite en notes : une seule voix, avec les liaisons nécessaires. Les accords, les paroles et les repères de structure peuvent être ajoutés.
