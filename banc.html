Banc d'essai mélodie

Génère un notebook Colab qui prend un seul fichier voix (par exemple morceau_vocals.opus), lance FCPE, RMVPE et Basic Pitch avec toutes les combinaisons de réglages que tu indiques, et exporte un fichier MIDI par variante dans un zip. Les MIDI se comparent ensuite dans Comparer des relevés.

Pour chaque réglage, écris une ou plusieurs valeurs séparées par des virgules : le notebook essaie toutes les combinaisons. Les variantes qui donnent exactement les mêmes notes sont écartées.

Fichier voix

Table des temps (facultatif)

Le fichier à fournir est le …_metadonnees.json du morceau : c'est celui qu'on ouvre dans Éditer les métadonnées, et qui est produit par le notebook de Préparer (il se trouve dans le zip du morceau ; tu peux aussi donner ce .zip directement).

Dans ce fichier, la clé structure contient : beats (la table de tous les temps), downbeats (les temps forts, début de mesure), beat_positions (le numéro de chaque temps dans la mesure), bpm, et segments (les sections : intro, couplet, refrain…). Ici, ce qui compte, c'est la table des temps et les temps forts ; les sections sont seulement recopiées pour être affichées dans « Comparer des relevés ».

Aucun des trois modèles ne reçoit la grille en entrée : elle sert à caler les notes après la détection, et à afficher les temps dans le comparateur.

Et ensuite ?

  • Ouvrez colab.research.google.com, puis Fichier → Importer un notebook et sélectionnez le fichier téléchargé.

  • Activez le GPU : Exécution → Modifier le type d'exécution → T4 GPU (utile surtout pour FCPE).

  • Lancez Exécution → Tout exécuter. Le notebook est déjà réglé selon cette page (détecteurs, source du fichier voix, table des temps) : il demande seulement d'envoyer le fichier voix (et, dans la même fenêtre, la table des temps si vous en avez prévu une : les deux fichiers peuvent être choisis ensemble). Les réglages restent modifiables dans la cellule « Réglages à tester ».

  • À la fin, un .zip de fichiers MIDI se télécharge. Chargez-le avec l'audio dans Comparer des relevés pour écouter et comparer.
